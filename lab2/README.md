# 实验二 搜索算法

总报告为[PDF阅读版](lab2_张凌琨_10241900443.pdf)，可编辑版本为[Word文档](lab2_张凌琨_10241900443.docx)，文本源稿为[Markdown](lab2_张凌琨_10241900443.md)。报告按四道题组织，包含算法设计、实验设置、结果分析和结论。[附录导航](LAB2_附录导航.md)列出了进一步实验和原始数据位置。

提交报告上限为5页；当前正式报告共5页。仓库只收录这份正式报告。

## 运行环境

Python 3.9及以上，四题求解器和实验脚本只使用标准库。保存的实验结果来自Windows 11与Python 3.12.14；复现信息保存在各结果目录的`reproducibility.json`，或`protocol.json`与`manifest.json`中，包含版本、种子、计时范围及源码/结果指纹。

## 运行四题

在本目录执行以下命令，可运行老师给定样例：

```text
python 题一/maze_astar.py
python 题二/weighted_astar.py
python 题三/alphabeta_tree.py
python 题四/treasure_game.py
```

| 题目 | 预期结果 | 详细说明 |
|---|---|---|
| 题一 | 包含起终点的7步最短路径，无解返回空列表 | [输入与运行说明](题一/README.md) |
| 题二 | 样例最小费用7，无解返回−1 | [输入与运行说明](题二/README.md) |
| 题三 | MAX最佳得分5，正式顺序为从左到右 | [输入与运行说明](题三/README.md) |
| 题四 | 完整6×6矩阵，H2选T2/−1，H4选T3/3 | [输入与运行说明](题四/README.md) |

Windows也可分别双击各题目录的`run_q1.cmd`至`run_q4.cmd`。脚本优先寻找本机已验证的Python，换电脑可安装Python后用上述命令，或设置各入口说明中的解释器路径。

## 原始记录说明
