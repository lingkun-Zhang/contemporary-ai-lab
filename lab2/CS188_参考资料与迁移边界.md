## 3. 迁移到本校Lab2前要重新对齐的规则

| 项目 | CS188资料中的约定 | 本校Lab2应采用的做法 |
|---|---|---|
| 输出与状态 | Search框架通常返回动作序列，状态接口由具体问题定义 | 题一返回坐标路径；题二返回整数最小费用；综合题自行定义完整状态 |
| 代价 | CS188有不同费用函数和常规搜索问题 | 题二明确E进入免费；题四A/B/T进入费为1。两题分别核对 |
| 深度 | Project 2的一层深度包含Pacman及全部ghost的一轮行动 | 题四H按题目四回合A→B→A→B理解，不直接套CS188的层数 |
| 访问顺序 | 官方Project 2的自动评分要求保持给定动作顺序 | 本校题三先按从左到右完成正式样例，再以不同顺序做受控拓展 |
| 相等剪枝 | 官方Project 2为匹配精确访问计数，要求相等时不剪枝 | 本校需按自己的算法与计数协议明确边界，不照搬另一门课的计数结果 |
| 成绩与验证 | CS188 autograder针对自己的输入和协议 | 不能据通过它就认定本校报告完整；还需逐条回答提示、给出实验和解释 |

上述CS188深度与剪枝协议直接见[官方Project 2说明](https://inst.eecs.berkeley.edu/~cs188/fa26/projects/proj2/)。本校部分依据课程《实验二要求_new(1).pdf》（课程文档未随仓库发布）。

## 4. 对后续实验设计最有用的借鉴

1. 题三先用可以手算的小树核对每个MAX/MIN值，再与无剪枝Minimax逐项比较；记录真正访问/评估次数和被跳过的分支。
2. 顺序对照使用完全相同树和叶值，分开正式左到右、反向及合理排序；根值应相同，成本可以不同。排序本身有开销时也纳入评价。
3. 题四先核对6×6距离矩阵，再固定状态、评价规则和深度比较两种搜索。分别解释H2、H4决策差异，不能用多做缓存掩盖模型定义错误。
4. 新优化提出后，保留原版、同内核不启用优化的对照，以及有收益/无收益输入；用自己的质量、工作量和成本数据支撑结论。

题一、题二已有研究应优先写清楚其证据和边界；无需因看到新仓库就重复增加同类实验。思考问题的显式回答与完成状态见 [Lab2核对表](LAB2_要求回答与证据核对.md)。
